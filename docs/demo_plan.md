# Demo Plan

## 90-Second Demo

### Goal

Show that MenuFlow AI turns a confusing restaurant menu into a clear, visual, personalized experience through Telegram.

### Demo Flow

1. Start in Telegram.
   Show that the user already has a saved profile with allergies, spice tolerance, and food preferences.

2. Send a menu photo to the bot.
   Explain that this is the main product entry point and takes only a few seconds in a real restaurant.

3. Open the personalized link first.
   Show that the menu is already adapted to the user:
   - safe and risky dishes are highlighted
   - allergens are flagged
   - spiciness is tagged
   - vegan or vegetarian dishes are visible

4. Point out the AI menu insight at the top.
   Explain that the app does not only translate the menu, it gives context about the cuisine, specialties, and what is worth trying.

5. Scroll through dishes.
   Show generated dish images, nutrition values, and possible allergens.

6. Open the generic link.
   Explain that this version can be shared with friends and still gives a full digital understanding of the menu.

7. Click `Personalize`.
   Show that another user can enter their own profile token and generate their own personalized version of the same menu.

### Closing Line

MenuFlow AI does not just translate menus. It turns any menu into a personalized digital dining experience that helps people choose confidently.
